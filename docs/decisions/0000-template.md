## Consequences

What follows from this decision? Cover:

- **Positive consequences** — what gets easier, faster, safer
- **Negative consequences / tradeoffs accepted** — what gets harder, slower, more constrained. Be honest. If you accepted a tradeoff, name it so you don't get blamed later for "not seeing it."
- **What needs to be true for this to remain the right call** — the assumptions. If one of these stops being true, revisit.
